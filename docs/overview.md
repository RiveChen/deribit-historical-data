# Overview

As is well known, [Deribit] have opened [Deribit API] for fetching in-time data like trades, quotes, etc. However, few people know that there is a `historical` endpoint for data fetching. (source)
Via `historical` endpoints, we are able to retrieve all transactions of futures and options in Deribit. This project is a Python-based tool for fetching, processing, and storing historical trade.
